# Hospital Patient Management System

A beginner-friendly Python project that manages patient information using
Object-Oriented Programming (OOP) and Exception Handling.

## Features

- Add a new patient
- View all patients
- Search for a patient using Patient ID
- Delete a patient
- Validate patient information
- Handle invalid user input
- Handle patients that are not found
- Prevent the program from crashing due to invalid input

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- Exception Handling
- Classes and Objects
- Constructors
- Methods
- Encapsulation
- try-except
- else
- finally
- raise
- Lists
- Loops
- Conditional Statements
